# 如何运行项目并看到效果

按下面顺序操作即可在本地跑起来。

---

## 第一步：准备数据库（MySQL）

1. 确保本机已安装 **MySQL 8**（或 5.7），并已启动服务。
2. 用命令行或 Navicat、DBeaver 等工具连接 MySQL，执行项目里的建表脚本：

**命令行示例（在项目根目录执行）：**

```bash
mysql -u root -p < docs/sql/schema.sql
```

按提示输入 MySQL 的 root 密码。  
脚本会创建数据库 `study_helper` 以及所有需要的表。

如果数据库账号不是 `root/root`，需要改后端配置（见第二步）。

---

## 第二步：修改后端配置（如需要）

打开 `backend/src/main/resources/application.yml`：

- **数据库**：若你的 MySQL 用户名/密码不是 `root` / `root`，修改这两行：
  ```yaml
  spring.datasource.username: 你的用户名
  spring.datasource.password: 你的密码
  ```
- **Ollama（可选）**：若已安装 Ollama 并拉取了 Qwen 模型，保持默认即可；若使用 Qwen3.5:0.8b，把 `model` 改为 `qwen3:0.8b`。

---

## 第三步：启动后端（Spring Boot）

任选一种方式：

**方式 A：用 IDEA / Eclipse 运行**

1. 用 IDEA 或 Eclipse 打开 `backend` 文件夹（作为 Maven 项目）。
2. 找到主类：`com.studyhelper.StudyHelperApplication`。
3. 右键 → 运行（Run）。

**方式 B：命令行（需已安装 Maven）**

```bash
cd backend
mvn spring-boot:run
```

**方式 C：未安装 Maven 时（推荐）**

在 `backend` 目录下用 PowerShell 执行（会自动下载 Maven 再启动）：

```powershell
cd backend
.\run.ps1
```

首次运行会下载 Maven 到 `backend\.mvn-local`，之后直接启动。

看到类似 `Started StudyHelperApplication` 即表示后端已启动。  
接口地址：**http://localhost:8080/api**（例如上传、列表、提炼、出题、问答都在此前缀下）。

---

## 第四步：安装并启动前端（Vue）

在**新的终端**里执行：

```bash
cd web
npm install
npm run dev
```

若 `npm install` 报权限错误，可尝试：

- 用**管理员身份**打开终端再执行，或  
- 在项目目录下执行：`npm install --cache .npm-cache`（使用当前目录作为缓存）。

启动成功后终端会提示：**Local: http://localhost:5173/**。

用浏览器打开：**http://localhost:5173** 即可看到「校园工具」页面。  
**注意**：注册/登录会请求后端接口，请务必**先启动后端**再在前端注册或登录；前端开发环境已配置为直接请求 `http://localhost:8080/api`（见 `web/.env.development`），若后端未启动会提示「无法连接后端接口」。

---

## 第五步：在页面上体验功能

1. **上传资料**  
   在「资料列表」页拖拽或选择上传一个 **.txt / .pdf / .docx** 文件（建议先用一个小一点的 .txt 试）。

2. **查看资料详情**  
   在列表里点击某条资料的「查看 / 提炼 / 出题」。

3. **提炼知识要点**（需本机已启动 Ollama 并拉取 Qwen 模型）  
   在资料详情页切换到「知识要点」Tab，点击「AI 提炼知识要点」。

4. **生成题目**（同样需要 Ollama + Qwen）  
   切换到「模拟题目」Tab，选择题目数量，点击「生成题目」。

5. **AI 问答**（需要 Ollama + Qwen）  
   顶部点「AI 问答」，输入问题后点击「提问」。

---

## 可选：启动 Ollama 与 Qwen 模型

若未安装 Ollama，**上传、列表、查看资料**仍可正常使用，但「提炼要点」「生成题目」「AI 问答」会因连不上模型而失败。

要使用 AI 功能：

1. 安装 [Ollama](https://ollama.com/)（Windows 下载安装包即可）。
2. 安装后打开命令行，执行：
   ```bash
   ollama pull qwen2.5:0.5b
   ```
   或：
   ```bash
   ollama pull qwen3:0.8b
   ```
3. 若使用 `qwen3:0.8b`，在 `application.yml` 里把 `spring.ai.ollama.chat.options.model` 改为 `qwen3:0.8b`。
4. 保持 Ollama 在运行（通常安装后会常驻），再在后端里使用「提炼」「出题」「问答」。

---

## 可选：运行微信小程序

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 打开开发者工具 → 导入项目 → 选择本项目下的 **miniprogram** 目录。
3. 在「详情 → 本地设置」中勾选 **不校验合法域名**。
4. 在 `miniprogram/app.js` 里把 `globalData.baseUrl` 改成你的后端地址（本机调试可填 `http://localhost:8080/api`；真机预览需填电脑局域网 IP，如 `http://192.168.x.x:8080/api`）。
5. 编译后即可在模拟器或真机上查看资料列表、资料详情（提炼/出题）、AI 问答。

---

## 常见问题

| 现象 | 处理 |
|------|------|
| 注册/登录提示「No static resource」或「无法连接后端接口」 | 先启动后端（见第三步），再刷新页面重试注册。前端开发时会直接请求 `http://localhost:8080/api`，确保后端在 8080 端口运行。 |
| 后端启动报错：连不上数据库 | 检查 MySQL 是否已启动；`application.yml` 里用户名、密码、库名是否正确；是否已执行 `docs/sql/schema.sql`。 |
| 前端 npm install 报 EPERM | 用管理员终端重试，或使用 `npm install --cache .npm-cache`。 |
| 提炼/出题/问答报错或超时 | 确认本机已安装并启动 Ollama，且已执行 `ollama pull qwen2.5:0.5b`（或 qwen3:0.8b）。 |
| 小程序请求失败 | 检查 baseUrl 是否与后端一致；本机调试勾选「不校验合法域名」。 |

按上述步骤做完后，就可以在浏览器（以及可选的小程序）里实际运行并看到效果。
