# 如何运行项目并看到效果

按下面顺序操作即可在本地跑起来。

---

## 第一步：准备数据库（MySQL）

1. 确保本机已安装 **MySQL 8**（或 5.7），并已启动服务。  
2. 在项目根目录执行基础建库脚本：

```bash
mysql -u root -p < docs/sql/schema.sql
```

3. **新库建议继续执行**（广场、公告、练习字段、小游戏排行榜等依赖这些脚本）：

```bash
mysql -u root -p study_helper < docs/sql/alter-question-attempt.sql
mysql -u root -p study_helper < docs/sql/alter-question-answer.sql
mysql -u root -p study_helper < docs/sql/migration_campus_announcement.sql
mysql -u root -p study_helper < docs/sql/migration_plaza.sql
mysql -u root -p study_helper < docs/sql/migration_games_all.sql
```

若数据库账号不是 `root` / 你在 `schema` 里使用的密码，请在后端 `application.yml` 中修改 `spring.datasource`（见第二步）。

---

## 第二步：修改后端配置（如需要）

打开 `backend/src/main/resources/application.yml`：

- **数据库**：修改 `spring.datasource.username`、`spring.datasource.password`（及 `url` 中的库名若不同）。  
- **通义千问（AI 必备）**：不要往仓库里写真实 Key。使用环境变量 `DASHSCOPE_API_KEY`，或复制 `application-local.yml.example` 为 `application-local.yml` 并填写 `dashscope.api-key`。详见 [DEPLOYMENT.md](DEPLOYMENT.md)。  
- **可选**：`dashscope.model` 默认为 `qwen-turbo`，可按控制台可用模型调整。

---

## 第三步：启动后端（Spring Boot）

任选一种方式：

**方式 A：用 IDEA / Eclipse 运行**

1. 打开 `backend` 作为 Maven 项目。  
2. 主类：`com.studyhelper.StudyHelperApplication`。  
3. 运行（Run）。

**方式 B：命令行（已安装 Maven）**

```bash
cd backend
mvn spring-boot:run
```

**方式 C：未全局安装 Maven（Windows PowerShell）**

```powershell
cd backend
.\run.ps1
```

首次运行会将 Maven 下载到 `backend\.mvn-local`。

看到类似 `Started StudyHelperApplication` 即表示后端已启动。  
接口根路径：**http://localhost:8080/api**。

---

## 第四步：安装并启动前端（Vue）

在新终端执行：

```bash
cd web
npm install
npm run dev
```

若 `npm install` 报权限错误，可尝试管理员终端，或：

```bash
npm install --cache .npm-cache
```

启动成功后访问 **http://localhost:5173**（「校园工具」）。

**与后端的连接方式（重要）**

- **推荐**：不在环境变量里设置 `VITE_API_BASE`（或保持注释状态）。此时 axios 使用相对路径 **`/api`**，由 Vite 开发服务器代理到 `http://127.0.0.1:8080`，见 `web/.env.development` 与 `web/vite.config.js`。  
- 请务必**先启动后端**再注册 / 登录；后端未启动时会提示无法连接接口。  
- 仅当你需要浏览器直连后端、绕过代理时，才在 `.env.development` 中临时设置例如 `VITE_API_BASE=http://127.0.0.1:8080/api`；**不要**写成 `/` 或其它非 `/api` 的相对路径，否则易出现静态资源 404。

---

## 第五步：在页面上体验功能

1. **注册 / 登录**  
   使用账号登录后即可访问资料、笔记、待办、打卡、广场等需登录页面。

2. **上传资料**  
   在「资料列表」上传 `.txt` / `.pdf` / `.docx`。

3. **提炼知识要点 / 生成题目 / AI 问答**  
   需已配置 **DashScope API Key** 且网络可访问阿里云接口；否则这些操作会报错。

4. **其它**  
   课程表、地图、公告、广场、练习、错题本、复习、报告、小游戏等可在侧栏或首页入口进入。

---

## 可选：运行微信小程序

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。  
2. 导入项目目录 **miniprogram**。  
3. 「详情 → 本地设置」勾选 **不校验合法域名**。  
4. 在 `miniprogram/app.js` 设置 `globalData.baseUrl`（本机模拟器可用 `http://localhost:8080/api`；真机请使用电脑局域网 IP）。  

---

## 常见问题

| 现象 | 处理 |
|------|------|
| 注册/登录提示无法连接后端 | 先启动后端；确认前端使用 `/api` 代理或正确的 `VITE_API_BASE`。 |
| 后端连不上数据库 | 检查 MySQL 是否启动；`application.yml` 中库名、账号密码；是否已执行 `schema.sql` 及所需迁移脚本。 |
| 广场 / 公告 / 排行榜报错 | 确认已执行对应 `docs/sql/migration_*.sql` 与 `alter-*.sql`。 |
| 提炼/出题/问答失败 | 配置 `DASHSCOPE_API_KEY` 或 `application-local.yml`；检查模型名与账户额度。 |
| 前端 npm install EPERM | 管理员终端重试，或使用 `npm install --cache .npm-cache`。 |
| 小程序请求失败 | 检查 `baseUrl`、手机与电脑是否同网、后端是否 `lan` profile 监听 `0.0.0.0`。 |

按上述步骤完成后，即可在浏览器（及可选小程序）中完整体验当前版本功能。
